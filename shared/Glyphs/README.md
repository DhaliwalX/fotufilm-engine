# Glyphs

Fotufilm's own symbols: the editor's deck circles (`fotu.deck.*`), the tabs inside each
deck (`fotu.tab.*`) and a low and high end for every slider (`fotu.slider.<field>.low|high`,
keyed by the `EditorControlField` raw value).

`sources/` is the only thing to edit. Everything else is generated by `tools/build-glyphs.py`:

| Output | Used by |
| --- | --- |
| `Glyphs.xcassets` | iOS, macOS and Final Cut: custom SF Symbols in nine weights and three scales |
| `web/public/glyphs/glyphs.svg` | the web app, as one sprite |
| `web/public/glyphs/<name>.svg` | anything else that reads SVG, such as Android Studio's vector import |
| `glyphs.json` | every platform: each glyph's rendering mode and colours, and the slider pairs |

## Using them

On Apple platforms, add `Glyphs.xcassets` to the target. The glyphs then behave like system
symbols: they follow the point size, weight and scale of the text beside them.

```swift
let image = UIImage(named: "fotu.deck.lens",
                    withConfiguration: UIImage.SymbolConfiguration(textStyle: .body))
imageView.preferredSymbolConfiguration = .init(hierarchicalColor: .white)
```

Glyphs listed as `multicolor` in `glyphs.json` carry system colours (the Color tab's hue ring,
the halation halo, the warmth and tint dots). Render those with `.preferringMulticolor()`. Their
uncoloured parts use `labelColor`, so they follow light and dark appearance by themselves.

On the web, reference the sprite and set the colour with CSS:

```html
<svg width="24" height="24" style="color: white"><use href="/glyphs/glyphs.svg#fotu.deck.lens"/></svg>
```

System colours default to their dark-appearance values. Override `--fotu-systemRed`,
`--fotu-systemBlue` and the others for a light page.

Glyphs that show brightness as fill (Highlights, Shadows, Paper Exposure) are drawn for dark
backgrounds. On a light background their fill reads as darkness instead.

## Editing

Each source is a 24 × 24 SVG drawn with 1.5-unit centre lines. Every element states:

- `data-mode`: `stroke` or `fill`.
- `data-layer`: `primary`, `secondary` or `tertiary`.
- `opacity`: optional.
- `data-colour`: optional, one of `systemRed`, `systemOrange`, `systemYellow`, `systemGreen`,
  `systemCyan`, `systemBlue`, `systemPurple` or `systemPink`.

Strokes are outlined for each weight, so keep a glyph's details at least 1.5 units apart; Black
strokes are 3 units wide. After editing, run:

```sh
python3 tools/build-glyphs.py          # rewrite the outputs
python3 tools/build-glyphs.py --check  # fail if the committed outputs are stale
```

The generator also records every glyph SVG in `SOURCE_ASSETS.json`, so commit that file with
the glyphs.

The generator needs `picosvg` (`pip install picosvg`).
