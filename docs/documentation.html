Fotufilm guide

Fotufilm adds a film look to photos and videos. This repository includes the engine, command-line tool, Mac app, Resolve and Final Cut plugins, and browser demo.

Build and open the app

Install Xcode 26 or newer and Halide. Run swift build to build the engine and swift test -c release --parallel to test it. Run macos/build.sh --test to build the Mac app.

Open build/macos/Fotufilm.app. Choose File → Open…, select a photo or video, and choose a film.

Film packs

The free Starter pack includes Gold 200, Tri-X 400, and Provia 100F. The app and plugins need no activation.

Choose Buy packs in the left sidebar to visit the pack store. To add a downloaded pack, click Load custom pack… at the bottom of the sidebar, or choose File → Import Film Pack… and select the .fotufilmpack file. You can then use its films offline. Loading a newer version of the same pack updates its films. If a pack needs a newer Mac app, Fotufilm asks you to update before loading it.

The Starter profiles use CC BY-ND 4.0. The code uses Apache-2.0.

Example print models

Example Photo Print and Example Projection use calculated curves with different contrast. Three photo and three projection models are available. They are examples, not measured paper profiles. The film strip offers photo prints for still gauges and projection prints plus Telecine for motion-picture gauges; the film name does not change the choices. The CLI and tests also include synthetic films and a generated colour chart.

The CLI IDs are ektacolor-edge, endura-premier, crystal-archive, vision-2383, vision-2393, and eterna-cp. These identifiers and the existing display names are preserved, so saved print selections continue to resolve. Existing complete colour grades still load; incomplete grades are rejected.

Plugins

Run resolve/build.sh --test or finalcut/build.sh --test to test a plugin. Building the installable Final Cut plugin also requires Apple's FxPlug SDK. See the Resolve guide and Final Cut guide.

Resolve controls

The inspector groups controls under Setup, Film, Exposure & Colour, Lens & Filters, Development, Grain, Halation, Colour Separation, and Output. Resolved Format, Resolved Medium, and Effective Renderer show the settings in use.

  • Film Frame Coverage (%) sets how much of the film frame you use.
  • Grain Animation follows the timeline or freezes the grain. Grain Seed lets you repeat a pattern.
  • Mottle changes coarse grain clumping. Return Spectrum adjusts halation across seven wavelength bands.
  • Render Mode selects Realtime or Reference. Disc grain needs a silver-image film and Reference mode.

Some controls depend on the film or stage you choose. For separate Negative Only and Print Only nodes, match their development settings, including Long Exposure (s).

Resolve and Final Cut fit finished prints to the timeline's colour gamut. Colours already inside it stay unchanged. This adjustment does not apply to density data or Texture Only output.
