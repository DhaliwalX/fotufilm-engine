Fotufilm engine source builds

This repository contains the engine, CLI, Mac application, Resolve OFX plugin, and Final Cut Pro FxPlug plugin.

Build and run

Install Xcode 26 or newer and Halide, then run swift build and swift test -c release --parallel. Build the Mac app with macos/build.sh --test. Launch build/macos/Fotufilm.app and use Open to choose an image.

The Mac app and plugins run without activation. The Mac app and plugins bundle the free Starter pack: Gold 200, Tri-X 400, and Provia 100F. The three calibrated profiles use CC BY-ND 4.0. Synthetic films remain available to the CLI and tests. Print receivers are analytic examples, and the demo image is a generated color chart.

Persisted print-medium identifiers are retained for format compatibility; source builds display them as Example Photo Print or Example Projection variants. Those variants use analytic receiver curves with different contrast.

Run resolve/build.sh --test for the OFX harness and finalcut/build.sh --test for the FxPlug harness. Building the actual Final Cut plugin requires the separately installed Apple FxPlug SDK.

Resolve controls

The inspector groups controls under Setup, Film, Exposure & Colour, Lens & Filters, Development, Grain, Halation, Colour Separation, and Output. Resolved Format, Resolved Medium, and Effective Renderer show the choices in use.

Film Frame Coverage (%) changes how much of the film frame is used. Grain Animation can follow the timeline or stay frozen; Grain Seed makes the pattern repeatable. Mottle controls coarse grain clumping, and Return Spectrum adjusts halation across seven wavelength bands. Controls are disabled when the film or pipeline stage cannot use them.

Use Render Mode to choose Realtime or Reference rendering. Disc grain requires a silver-image stock and Reference rendering. Match development settings across split Negative Only and Print Only nodes, including Long Exposure (s).

Resolve and Final Cut fit finished prints to narrower timeline color primaries before encoding them. Colors already inside the target gamut stay unchanged. Density data and Texture Only output are not treated as finished prints.

See the Resolve guide and Final Cut guide for installation and setup.

Build support · Repository guide

To add downloaded profiles, choose File → Import Film Pack… in the Mac app and select the .fotufilmpack file. Installed packs work offline. Purchasing profiles does not unlock or limit app features.
