Build support

Use a full Xcode 26 or newer installation and select it with xcode-select. Install Halide with Homebrew or provide a compatible toolchain through HALIDE_ROOT.

The Final Cut plugin needs Apple's FxPlug SDK. Without that SDK, the Mac app builds with the Resolve plugin only. The FxPlug host harness does not need the SDK.

Custom pack builds must supply both FOTUFILM_PACK_KEY_SOURCE and FOTUFILM_SEALED_PACKS as absolute paths outside this checkout. Supplying only one is an error. Keep pack key material outside version control.

Check proposed source files with python3 tools/check-source-boundary.py. New images, data files and third-party headers require documented provenance in SOURCE_ASSETS.json.

If a Resolve control is disabled, check Stage, Resolved Format, Resolved Medium, and Effective Renderer. Custom Mottle needs Full and clump-field grain. Discs needs a silver-image stock and Reference rendering. Negative Only outputs density data; use Full with Output Medium set to Negative to view a negative image.

CI is started manually in GitHub Actions. Rendering and plugin tests require a working Metal device.
